# code-review-agent2
Homework 2：多 Agent 代码开发与修复工作流
1. 项目简介
本项目使用 Python 和千问（DashScope）模型，构建一个由三个 Agent 按顺序协作的简单工作流（MVP），用于分析开发任务、提出代码修复方案，并生成测试建议与审查报告。

工作流执行顺序：
1. Agent 1：需求与代码分析——分析任务目标、现有代码中的潜在问题及验收标准。
2. Agent 2：方案设计与代码修复——参考 Agent 1 的分析，生成设计方案或代码修复建议。
3. Agent 3：测试与审查——审查前序结果，提出测试用例，并给出交付审查结论。
程序通过共享状态字典保存 Agent 输出、消息记录、执行状态、耗时和错误信息。工作流结束后，会将结果写入 Markdown 报告，并在终端及日志文件中输出运行信息。
2. 当前功能
- 顺序调用三个 Agent，并将前序结果传递给后续 Agent。
- 根据用户是否提供现有代码，选择代码分析与修复模式或需求分析与方案设计模式。
- 记录 Agent 执行状态、耗时、消息传递和错误信息。
- 将执行日志写入 workflow.log。
- 自动生成或更新 workflow_report.md。
- 对 API 返回状态、空响应和异常情况进行基本处理。
功能说明： Agent 3 目前生成的是测试计划与审查建议，程序不会自动执行模型生成的代码或测试用例。因此，报告中的测试用例不代表已经实际运行或通过测试。
